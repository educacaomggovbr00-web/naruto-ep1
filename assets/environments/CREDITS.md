# Cenários 2.5D

Arte criada com a ferramenta de geração de imagens para este projeto de fã, com direção visual e layout do próprio jogo como referência. Não são capturas de jogos comerciais.

- `konoha-premium.png`: praça, Academia, armazém, ramen, canal e ponte.
- `training-premium.png`: campo de treino com cerca e área aberta.
- `forest-premium.png`: clareira noturna para a perseguição de Mizuki.

Os desenhos têm perspectiva fixa. Luz e detalhes de ambiente fazem parte da pintura; o jogo acrescenta câmera, partículas, correção de cor e interface em tempo real. Não se trata de um cenário 3D ou de uma versão para PlayStation.

Naruto e elementos associados pertencem aos respectivos titulares. Uso em protótipo independente de fã.

- `duel-arena.png`: arena lateral de treino, gerada em 17/10/2026 usando o campo de treino como referência de estilo. Personagens, interface, projéteis e impactos são renderizados separadamente pelo Godot.
